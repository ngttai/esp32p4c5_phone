# Emote pack

Eye animations for the AI Assistant app, in EAF format (360 x 360, 8-bit), plus `listen.eaf` (100 x 46).

They come from the `assets/emote/emoji_large` folder of the author's esp_chatbot_v1 project, which takes them
from Espressif's [Emote Pack.zip](https://dl.espressif.com/AE/Emote%20Pack.zip), linked from
[espressif2022/esp_emote_gen_player](https://github.com/espressif2022/esp_emote_gen_player). The downloaded pack
has no license file: the license of these assets is not confirmed.
